# Activities – Naloga 5

## Opis naloge

Aplikacija Activities je izdelana v Android Studiu z uporabo Jave in XML.
Namen naloge je povezovanje treh aktivnosti, prenos vrednosti števca
med zasloni in uporaba potezne navigacije.

## Delovanje aplikacije

- **MainActivity** prikazuje števec in gumba za prehod na drugo in tretjo aktivnost.
- **COUNT** ob vsakem kliku poveča števec za ena.
- **HelloActivity** prikazuje napis Hello! in trenutno vrednost števca.
- **ThirdActivity** prikazuje napis Activity 3, preneseni števec in gumba za prehod na prvo ali drugo aktivnost.
- **Intent** omogoča prehode med aktivnostmi.
- **putExtra()** in **getIntExtra()** omogočata prenos vrednosti števca.
- **OnSwipeTouchListener** omogoča potezno navigacijo na tretjem zaslonu.
- Poteg proti levi odpre prvo aktivnost, poteg proti desni pa drugo aktivnost.

## Uporabljene tehnologije

- Android Studio
- Java
- XML
